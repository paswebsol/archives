Automatic backup

The app creates an internal recovery snapshot while it is open. You can save a separate backup to a USB flash drive or external SSD by connecting it to your computer and selecting that drive in the save-location picker. Automatic external writes work only while this app is open and the browser grants file access.

How to back up to a USB drive or external SSD
  1. Connect the USB drive or external SSD to your computer and make sure it appears in File Explorer/Finder.
  2. Select Choose USB / SSD location. In the save dialog, browse to the connected drive and choose a backup filename.
  3. Leave Business Archives Pro open and the drive connected for scheduled external updates. Use Back up now to USB / SSD whenever you want an immediate copy.
  4. Safely eject the drive after the backup has finished. Keep a second backup in another safe place.

If your browser does not support selecting a save location, choose Download backup for USB / SSD, then copy the downloaded JSON backup file to the connected drive using your device file manager. On phones/tablets, manual download and copy may be required. The app cannot write to a disconnected drive or silently bypass browser permissions.

For security, keep backup drives private because archive records may contain confidential business information. You may need to select the drive again after reopening the app.

Backup and restore
